## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/` (local-markdown tracker; no git remote). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
